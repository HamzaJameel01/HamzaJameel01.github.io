The problem

Steel Angel has to text an emergency contact after a crash, when the rider may not be able to touch the phone. Every React Native SMS library I tried only opened the messages app and waited for someone to tap Send.

What I built

A native module that sends SMS silently in the background on Android through Kotlin's SmsManager, with multipart splitting and delivery tracking. On iOS, where Apple blocks silent sending, it opens a pre-filled Swift compose screen through the same API.

npm install react-native-background-sms
  • One typed API for both platforms, with a clear result: sent, failed, cancelled or unavailable.
  • Long messages split automatically into multipart SMS on Android.
  • Delivery tracking through a BroadcastReceiver with a 30-second timeout.
  • Multiple recipients, one SMS each, sent in order.
import { sendSms } from 'react-native-background-sms';

const result = await sendSms({
  phoneNumbers: ['+923001234567'],
  message: 'Crash detected near Lahore. Location: …',
});

if (result.status === 'sent') markAlertDelivered();
import { canSendSms } from 'react-native-background-sms';

const { available, reason } = await canSendSms();

if (!available) {
  // e.g. no SIM card, or SMS not supported
  showFallback(reason);
}
